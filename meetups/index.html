Building a dementia screener with Claude Cowork and medical literature

A free, three-gate cognitive screening protocol built from validated instruments (SLUMS, IQCODE, ACE-III, SAGE). Caregivers run it at home in about 20 minutes and get a clinician-ready handoff packet. Not a diagnosis, but the start of one.

Un-slopping my app with adversarial agents

ConvoLab, a daily Japanese flashcard app, worked fine. The code was slop. Andrew rebuilt the backend using the working app as the spec, with one agent writing and Claude reviewing.

~13review rounds per PR
43 hrssecond pass runtime

8.6 → 9.8CodeScene health
andrewlandry.com
  • One concern per PR. Business logic owned by the API.
  • Local agent writes and fixes; Claude reviews and challenges. Repeat until reviews and checks pass.
  • Babysat the first ten PRs to set patterns (UUIDs, transactions, DTOs), then let the agents run for days.
  • Two kinds of review: CodeScene for smells and hotspots, Claude for behavior, logic, and missing tests. Merge only when the score improves.
"Independent review made it workable. I still needed tests, measurement, and judgment."

Adam SchifferdeckerFounder, Triangle Startups

1,300 agent-written commits. Now I can build as a generalist.

Claude Code made a software-first company possible for one person with a chemistry, health care, and strategy background.

triangle-startups.com
  • Every session starts with the same two files: AGENTS.md for how the repo works, CONTEXT.md for what the product is.
  • A post becomes three source-verified changes and a reviewable PR. Adam merges or rejects.
  • Every factual intake hits the same gate: claim, source, verification, then human review.
  • Where it broke: an incomplete search turned an existing startup into a "new" intake.
"I didn't need a new career. I needed a way to build."

If you're starting this week: put your rules in the repo. Say what would prove the change wrong. Keep the merge, and every irreversible action, human.
